# Workout Hub (React Native + TypeScript)

Offline-first workout logging app built with React Native + TypeScript. Tracks sessions, exercises, and sets locally with clean data integrity.

## Features
- Create workouts with exercises + sets
- Workout history (sessions saved by date)
- Offline-first local persistence (AsyncStorage)
- Structured TypeScript models (numbers stored as numbers)
- Clean UI focused on serious lifters

## Tech Stack
- React Native (Expo)
- TypeScript
- AsyncStorage
- React Navigation

## Run Locally
```bash
npm install
npm start
